# left-pad

This is the `left-pad` pattern to be implemented by Flying Buttress. It pads the start of a stringified value to a given length using a fill character (default: space).

- Spec: `spec/SPEC.md`
- Usage examples: `docs/USAGE.md`
- Type declarations: `types/left-pad.d.ts`
- Tests: `tests/leftPad.test.js` — run with `bun test`

Do not modify the spec, tests, or type declarations unless that is explicitly the task.
