# left-pad
## a Flying Buttress spec

```ts
import leftPad from 'left-pad'

leftPad('foo', 5)
// => "  foo"
```

A utility for padding the start (left) of a string with zeros (by default). The final length of the string is specified as a parameter to the function.

To be implemented by `buttress` for usage in any JavaScript or TypeScript project.
